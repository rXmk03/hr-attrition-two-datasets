Part 1.3 — Data Analysis

Protocol — identical for both datasets

  • Inspect: shape, missing values, placeholder strings, value ranges, distinct counts, duplicates
  • Drop constant and identifier columns, then de-duplicate
  • One-hot encode categoricals with drop_first=True
  • Stratified 80/20 split, random_state=42
  • Random Forest and MLP (scaler fitted on training data only, inside a Pipeline)
  • class_weight='balanced' comparison, decision-threshold sweep
  • Permutation importance on both models, so rankings are measured the same way
  • Effect-size checks on top features, and a correlation check

Model choice: MLP is the model that differs from previous coursework. Random Forest was used previously and is retained for its interpretability.

Evidence for the metric justification (Q2)

  • Accuracy fails on imbalanced data. On Dataset A the trained model (0.833) scored below a rule predicting nobody leaves (0.840), while catching 5 of 47 leavers.
  • The two errors carry different costs. A false alarm is a retention conversation. A miss is an unplanned resignation — recruitment, lost knowledge, team disruption.
  • Metric choice changes the winner. On Dataset A accuracy ranks RF above MLP (0.833 vs 0.820); recall ranks MLP three times higher (0.34 vs 0.11).
  • Precision must sit alongside recall. At threshold 0.10, Dataset A reaches 0.96 recall by flagging 196 of 294 employees — operationally useless.
  • Where to stop is a business judgement. How many retention conversations can HR actually hold?

Limitations to declare

  • Threshold on Dataset A selected by inspecting the test set — optimistic estimate.
  • class_weight='balanced' failed on both datasets for opposite reasons: on A the model was ignoring the minority class but the constraint was the voting threshold; on B it was not ignoring it at all. Class weighting is not an automatic remedy.
  • Permutation importance measured at whatever threshold predict() uses (0.5), which for Dataset A was a configuration the analysis had rejected. Re-measured at 0.25 for comparison.
  • Dataset A is explicitly fictional. Dataset B's near-perfect separability suggests it is also synthetic. 99% accuracy is not characteristic of real attrition prediction.
  • Dataset B tenure bands at 7, 8 and 10 years contain 94, 81 and 107 employees and all show exactly 0.000.
  • Effect-size checks are bivariate — no controlling for other variables except the one age-band check.
  • Workload is measured differently in the two datasets, so only direction is comparable.
